# Archive

These are records from before ship-sop became self-contained: session logs (`recent-work/`, `RECENT-WORK.md`), the agent-memory notes (`agent-memory/`, `agent-memory.md`) and the phase build plans (`build-plans/`). Nothing reads them: no script, test, workflow or live document depends on them, and they are no longer written. They are kept, with their git history, as a record of how the project got here. Current state is in `Backlog.md`, the README and the code.

Older Backlog entries and `docs/backlog-archive.md` cite these files at their pre-archive paths (`docs/agent-memory/`, `docs/recent-work/`, `docs/build-plans/phase-*.md`); those citations are dated history and were left as written.
